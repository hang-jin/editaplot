# 时间–频率数据合同

我用这个模板展示已经在上游完成处理的时频数据，而不是把原始脑电直接变成频谱。
请准备 Time (s)、Frequency (Hz)、Power (dB) 这样的三列长表，每行对应一个时间×频率单元。
列名可以是中文，单位也可以是毫秒或其他明确单位；我不会自行换算或猜测单位。

两个坐标均需至少两个点、等距且单调，所有组合都必须存在。递增和递减顺序原样保留。
不补缺格、不排序、不插值、不裁掉极值，不把负dB自动当成负变化。其他列保留在工程里，
但需先确认用途。若数据缺格或坐标非等距，我会说明原因，请你在上游整理后再提供。

色标表达原值高低，不做归一化、基线扣除、对数转换、滤波、FFT/STFT或小波计算。
示例81×121共9801个单元完全由我拟定，只用于展示，不代表真实脑电结果。
