# XPS 多谱线对比视觉合同

- 使用白色背景、Arial 字体、真实结合能和强度坐标，不添加装饰网格或装饰性 3D。画幅按谱线数量、标签长度和数据密度自适应，不继承固定 C 1s 专用画幅。
- X 轴标题为 `Binding Energy (eV)` 或用户确认的等价标题，高结合能在左、低结合能在右。不得通过 `x.reverse=1` 实现方向；源数据保持原样。
- 默认 `overlay`：每条实测谱线绘制为独立可编辑实线，不在稠密采样点逐点添加符号。相互无序的样品使用克制比较色；温度、时间、浓度等有序条件使用同一低饱和色系的连续梯度。
- `stacked_offset` 只在用户明确确认后启用。显示偏移必须通过 Origin 内部 helper 列实现并在计划、工作簿和验证报告中记录；图轴或图注必须明确表示存在显示偏移。
- 图例文字仅来自经确认的源列名，图例无边框，可放在图内空白区或图外。图例遮挡不影响可编辑交付，但视觉检查应记录其位置。
- Y 轴保留真实刻度和标题；不继承固定 C 1s 隐藏 Y 数字的规则。只有用户确认无可比绝对单位时才使用 `Intensity (a.u.)`。
- 本模板不绘制拟合包络、背景、分峰、残差或填充区域，也不复制参考论文中的峰位数字、化学态文字、箭头、面板字母或结论性注释。
- 成功必须包含非空且可编辑的 OPJU、PNG、PDF、TIF，以及坐标轴方向、字体、线宽、系列颜色、显示模式、helper 偏移和源值未改动的反读；PNG 预览不能单独作为成功证据。
