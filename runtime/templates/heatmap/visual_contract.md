# 热力图视觉合同

- 原始宽表保留在 Source 工作表；Origin 内部创建矩阵和标签 helper sheets，不回写源文件。
- 非负或单向数据使用 Viridis 感知均匀色阶；跨零数据使用发散色阶，颜色方向写入并反读。
- 小矩阵显示自适应黑白数值标注；高密度矩阵自动关闭标注，避免文字堆叠。
- X 标签使用官方 dataset 绑定；行文字和源行顺序冻结在绘图方案中，稀疏显示只隐藏标签，不删除矩阵值。
- 普通热图的可见 Y 行标签使用独立、无框、可编辑的 Origin 页面文字，按源行中心定位。
  在写入源文字前关闭动态替换（官方 `GObject.link=0`），并反读；不把行名中的符号当成表达式。
  隐藏原生重复 Y 标签，以实际测量宽度右对齐，文字右缘与左边框默认保留 0.20 cm 正间距。
  不用缩小字号或裁剪导出图来掩盖长标签；放不下时应改短标签或调整页面。
- 字体、字号、准确文字、页面附着、旋转、实际文字框、逐行对应及物理间距在导出后重新反读；
  页面内但侵入数据框也必须失败。保存的 OPJU 必须可独立重开后继续编辑和验证。
- 预览使用同一冻结行标签锚点。混淆矩阵的轴标题和标签规则不受此普通热图修复影响。
- 颜色刻度字号、位置、标题可见性及页面物理尺寸均独立反读验证。

文字动态替换属性依据 [Origin 官方图形对象属性](https://docs.originlab.com/labtalk/ref/graphic-objs/)；
`link=0` 表示不链接替换，已先在独立 2024b 小实验中验证，不用于执行用户数据中的表达式。
