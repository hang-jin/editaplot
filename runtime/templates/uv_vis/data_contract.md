# 数据合同

主图需要波长和至少一条吸光度/透过率数值列。支持单样品和多样品宽表，系列顺序严格保留
源列顺序。同一图中的主信号应使用一致的物理定义和单位；Absorbance 与 Transmittance
不能在没有明确双轴合同的情况下混画。

可选 Tauc 插图必须同时提供 `Photon energy` 与预计算 `Tauc value`；`Tauc fit` 和
`Band gap` 也必须由用户提供。软件不从波长计算光子能量，不选择直接/间接跃迁指数，
不拟合外推线，不计算带隙。

- 不自动平滑、扣背景、归一化、求导或寻找吸收边。
- 波长加未知数值系列但没有 Absorbance、Transmittance、吸光度或透过率语义时，必须让用户确认。
- 参考论文中的样品照片、箭头、虚线、溶剂文字和面板字母不属于自动绘图元素。
