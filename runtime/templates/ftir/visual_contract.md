# FTIR / IR 视觉合同

- 白色背景、Arial 字体、清晰递减波数轴和真实信号坐标；不添加装饰网格。
- 多条件系列使用低饱和、连续且顺序稳定的同一配色家族，避免无序彩虹色和超过配色容量后的颜色循环。
- 稠密光谱默认使用独立可编辑实线，不在每个采样点叠加符号；线宽、页面和图层随系列数自适应。
- 图例名称只来自源列名。图例可移到图外，且不使用外框。
- 不复制参考论文中的箭头、峰位文字、官能团名称、阴影区、面板字母、照片或其他版式元素。
- 不自动标注峰位。用户后续可以在可编辑 OPJU 或排版软件中补充经过确认的注释。
- 成功必须包含非空且可编辑的 OPJU、PNG、PDF、TIF，以及坐标轴、字体、线宽、系列颜色和轴方向反读。
