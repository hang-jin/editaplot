# FTIR / IR 数据合同

- 第一列为波数，推荐列名 `Wavenumber (cm^-1)` 或 `波数 (cm^-1)`。
- 其余列为用户提供的吸光度或透过率数值系列；同一张图中的系列应使用可比较的信号定义和单位。
- 支持单样品、多样品和按温度、时间或处理条件排列的宽表系列。系列顺序严格保留源表列顺序。
- 波数轴按红外光谱惯例从高波数向低波数显示，但不会改变、重排或覆盖源文件。
- 默认直接绘制源值。新的纵向显示偏移必须由用户明确确认，并且只能作为 Origin 内部 helper 数据保存。
- 不自动做基线校正、平滑、归一化、去噪、峰识别、峰指认、峰面积计算或官能团推断。
- 非数值说明列必须在语义确认中标为“保留但不绘制”或“忽略”，不能自动变成曲线或图内文字。
