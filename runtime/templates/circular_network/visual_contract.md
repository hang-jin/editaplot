# 环形有向加权网络图视觉合同

- 使用 1–4 个自适应小面板；每个面板将已确认的节点顺序放在同一单位圆上。相同节点跨面板必须保持同一位置和节点组颜色。
- 有向边使用可编辑的平滑曲线与目标端箭头。互为反向的两条边必须使用相反曲率，不能完全重叠。
- `Weight` 在全部面板范围内通过同一个冻结的线性映射编码为 1.2–4.2 pt 线宽；不改变源权重，也不为每个面板单独缩放。
- `Sign` 使用克制且色盲友好的语义色：positive 为低饱和蓝绿色，negative 为珊瑚红，neutral 为中性灰；方向与正负不能只依赖颜色区分。
- 节点组硬限制为最多四组，每组使用一个稳定且不循环的低饱和颜色。超过四组必须停止并提示用户整理分组；在增加形状或纹理等独立可读编码前，不得用循环颜色伪装成可区分组。
- `EdgeLabel` 的显示决策冻结在共享 plot plan 中：单面板不超过 12 条边时显示用户提供的标签，超过 12 条边时默认隐藏该面板的边标签。隐藏只影响显示，源列和 Origin 源数据工作表必须完整保留；权重线宽图例和正负语义图例仍须保留为可编辑对象。
- 页面尺寸随面板数、节点数和标签长度扩展，不继承固定 XPS 画幅。白底、Arial；面板标题 20 pt，节点/图例 17 pt，线宽和物理字号必须写入 Origin 后反读。
- 默认不显示坐标轴、装饰性网格、阴影或 3D 效果。不得把参考位图嵌入图中冒充可编辑网络。
- 正式交付必须同时包含 OPJU、PNG、PDF、TIF、节点/边/线宽/颜色/文本对象反读和人工视觉检查。
