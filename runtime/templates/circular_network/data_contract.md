# 环形有向加权网络图数据合同

## 必需列

- `Panel`：面板、阶段或时期名称。支持 1–4 个非空面板，按源表首次出现顺序形成候选顺序，并在语义确认后冻结。
- `Source`：有向边的起点节点。
- `Target`：有向边的终点节点。
- `Weight`：边的正数权重，必须是大于零的有限数。原值保持不变，仅用声明并冻结的线性映射转换为显示线宽。

## 可选列

- `Sign`：只接受 `positive`、`negative` 或 `neutral`。缺失时表示“未提供符号”，按中性色显示，不能自动推断为正相关。
- `SourceGroup`、`TargetGroup`：节点类别，用于稳定的节点填色。同一节点在全部面板和全部行中的类别必须一致，全部数据最多包含四个节点组。
- `EdgeLabel`：用户提供的边标签。单面板超过 12 条边时，该面板的标签默认不显示；原文字仍完整保留在 Origin 源数据工作表中。

## 完整性规则

- 每行是一条有向边；不接受空节点、自连接或同一面板内重复的 `Source → Target`。
- 节点候选顺序来自源表中 `Source`/`Target` 的首次出现顺序，必须在绘图前向用户展示并冻结；绘图层不得按度数、权重或聚类静默重排。
- 不计算相关系数、因果方向、中心性、显著性或缺失权重，也不合并重复边。
- 原文件保持只读。Bezier 曲线采样点、箭头辅助点和显示线宽只允许作为 Origin 工作簿内部 helper columns。
