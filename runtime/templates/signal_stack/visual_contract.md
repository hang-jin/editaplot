# Common-amplitude signal stack

Preserve every source time/amplitude and channel identity. Only explicitly approved additive
channel offsets are used. A native editable line object in the right page gutter represents a
length in the same amplitude units; it is not a measurement, estimate or error bar.

Keep X limits equal to the source time extent. Put direct channel labels in a separate left page
column, keeping source order. Hide numeric Y ticks while retaining the amplitude/display-offset
title. Use Arial 20pt titles, 17pt ticks/direct labels and 1.4pt traces. Size the physical page
from channel count and measured label lengths; preserve fonts instead of shrinking them.

Only a newly created empty owned layer may have inherited visible template objects cleared.
User template files and existing projects are untouched. Verify original source and helper arrays,
each plot's source binding/count, physical page/layer geometry, both axes, direct text, ruler
coordinates/zero arrowhead dimensions, colors, widths, all four exports and saved-project reopen.
