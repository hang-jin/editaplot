# 多通道信号数据合同

我用这个模板展示已经处理好的信号长表：Time (s)、Channel、Amplitude (uV)。
中文列名也可以，时间和幅度单位请明确写在括号内。每通道至少两个点，时间已严格递增；
各通道可以有不同的采样时间，我会保留原值和原顺序。

为了把通道分开看，我只给每条轨迹加一个明确、需要确认的纵向显示偏移；原始数据不改。
所有通道保持共同幅度比例。右侧标尺只是所给单位的一段长度，不是误差棒或统计量。
标签保留原通道名，页面按名字长度和通道数扩展；横轴只有真实时间范围，纵轴不显示偏移后的数字。

我不做滤波、去噪、去伪迹、重参考、插值、居中或逐通道归一化；原始设备数据请先在上游处理。
教学表的8008个数值由我拟定，仅用于演示，不代表真实受试者或电极位置。
